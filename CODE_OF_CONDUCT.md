# Code of Conduct

## Our pledge

We aim to make participation in this project welcoming and respectful for people with different backgrounds and levels of experience.

## Expected behavior

Be considerate, constructive, and respectful. Focus on technical issues, provide context, accept good-faith correction, and respect privacy. Do not post another person's account data, credentials, private messages, or identifying information.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, targeted disruption, and publishing private information without consent are not acceptable.

## Reporting and enforcement

Report conduct concerns privately to the repository owner through the GitHub profile or repository contact controls. Include links and a concise description; do not publish sensitive material in an issue. The maintainer may edit or remove content, close discussions, or restrict participation based on the circumstances. This project follows the Contributor Covenant 2.1 principles; see https://www.contributor-covenant.org/version/2/1/code_of_conduct/ for the full upstream text.
