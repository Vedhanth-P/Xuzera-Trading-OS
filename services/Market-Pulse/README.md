# Optional Market Pulse connector

Xuzera can read a local Market Pulse API when it is installed and running. Its absence is normal: the dashboard falls back to the public feeds it already supports.

The source from [srinivasBJ/Market-Pulse](https://github.com/srinivasBJ/Market-Pulse) is not redistributed here because the upstream checkout reviewed for this release did not contain a license. If you separately obtain it and its current terms permit use, follow its upstream setup guide and start it independently. Xuzera's MIT license does not apply to that source.
